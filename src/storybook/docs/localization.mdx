    <Heading level="h3">Set up the provider</Heading>

    <Text maxW="prose">
      Add one <code>LocaleProvider</code> near the app root. Pass the user's
      locale and the translations you have. A label you leave out keeps its
      English default, so you can translate in steps.
    </Text>

    ```tsx
    import { LocaleProvider } from 'cetec-design-system';
    import { useTranslation } from 'react-i18next';

    export function AppShell({ children }) {
      const { t, i18n } = useTranslation();

      return (
        <LocaleProvider
          locale={i18n.language} // for example "fr-FR"
          labels={{
            closeDialog: t('ds.closeDialog'),
            noResults: t('ds.noResults'),
            moreSelected: (count) => t('ds.moreSelected', { count }),
          }}
        >
          {children}
        </LocaleProvider>
      );
    }
    ```

    <Text maxW="prose">
      Without a provider, every component uses <code>en-US</code> and the
      English defaults. Nothing breaks.
    </Text>

    <Heading level="h3">Labels that hold a value</Heading>

    <Text maxW="prose">
      Some labels include a number or a name, such as "3 more selected". These
      labels are functions. Pass a function that calls your translation tool,
      so it can apply its own plural and word-order rules.
    </Text>

    ```tsx
    labels={{
      moreSelected: (count) => t('ds.moreSelected', { count }),
      removeItem: (item) => t('ds.removeItem', { item }),
    }}
    ```

    <Heading level="h3">Adding built-in text to a component</Heading>

    <Text maxW="prose">
      Never write a user-facing string, including an <code>aria-label</code>,
      directly in a component. Add a key to <code>LocaleLabels</code> in
      <code>src/system/context/locale-labels.ts</code> with an English default,
      then read it with <code>useLocale()</code>. If the component already has a
      label prop, use the label as that prop's default.
    </Text>

    ```tsx
    const { labels } = useLocale();
    const { clearLabel = labels.clearDate, ...rest } = props;
    ```
